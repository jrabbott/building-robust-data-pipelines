# Building robust data pipelines

Reveal.js slide deck for the talk presented by **Darren Hutton** and **Jonathan Abbott** (Hippo Digital).

**Live deck:** [https://jrabbott.github.io/talk-building-robust-data-pipelines/](https://jrabbott.github.io/talk-building-robust-data-pipelines/)

## Requirements & run locally

- **Node.js 22+** (see `.nvmrc`). Prefer `npm ci` so the lockfile is respected.

```bash
npm ci
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173/talk-building-robust-data-pipelines/`).

## Present

1. Start with `npm run dev` (or open the live Pages URL).
2. Click the slides, then use arrow keys / space to navigate.
3. Press `F` for fullscreen, `S` for speaker notes, `Esc` for overview.
4. Slide numbers and URL hashes are enabled so you can deep-link to a slide.
