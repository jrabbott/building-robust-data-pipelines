Medallion what?

Medallion Pattern

Represents an increasing quality of data in the stores

  • Simple data model
  • Allows for multiple processing (replay, time-travel)
  • Supports ACID transactions (atomicity, consistency, isolation, and durability)
  • Supports incremental ETL
Data doesn't have to be constrained to a particular processing model. Each layer can be mixed mode, the most appropriate one chosen for the data set/entity. Bronze — Data in its rawest form. Silver — Cleansed and conformed (typically joined with some reference data). Gold — Curated and finalised data; data warehouses are often included in this tier.

Bronze layer

The bronze layer contains unvalidated data. Data ingested in the bronze layer:

  • Maintains the raw state of the data source.
  • Is appended incrementally and grows over time.
  • Combination of streaming and batch transactions.

Silver layer

Bronze layer contains the entire data history. Silver layer represents a version of the data that is:

  • Validated
  • Enriched
  • Trusted by downstream analytics.

Gold layer

Highly refined and aggregated, containing data for power analytics, machine learning, and production applications.

Gold represents data that has been transformed into knowledge, rather than just information.

Analysts rely on gold for their core responsibilities.

Aggregations, joins, and filtering are handled before data is written to the gold layer — users should see low latency query performance on data in gold.
